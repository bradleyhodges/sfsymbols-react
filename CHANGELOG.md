# Changelog

## 8.1.1 - 2026-09-07

- Share one memoized, ref-forwarding SVG renderer between the established styled entry and the new dependency-light `/unstyled` entry.
- Add native dimension precedence, accessible descriptions and deterministic IDs, explicit SVG composition, safe per-path props, and source-opacity preservation.
- Add validated, immutable keyword and prototype-safe variant metadata helpers with public additive TypeScript types.
- Support React 18 and 19 as peer hosts and publish explicit ESM, CommonJS, and declaration conditions for every public entry.
- Replace destructive clean-first compilation with a staged, validated package build that preserves the previous distribution on failure.
- Add an optional local VS Code extension for safe hover previews and exact per-icon import insertion.
- Add packed-consumer, browser hydration, full-catalogue, React-version, TypeScript, bundle-boundary, and Next App Router verification fixtures.
